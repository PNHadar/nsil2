# Mass General Brigham — Neuroscience Institute Launchpad (`nsil2`)

Live GitHub Pages URL: [https://pnhadar.github.io/nsil2/](https://pnhadar.github.io/nsil2/)

An institutional landing page for the **Mass General Brigham Neuroscience Institute (NSI) Launchpad**, developed in partnership with **MGB Innovation**.

## Program Overview

- **Stage 1 Incubator**: 3–5 teams selected for the inaugural cohort • ~12 weeks (weekly structured curriculum, Mentor Network access, company-formation guidance, Demo Day, and non-dilutive prize award). Open to any MGB employee with a plausible neuroscience company idea; no prior IP, prototype, or existing company required.
- **Stage 2 Accelerator**: Up to 3 ventures in the first cycle • ~6 months of individualized venture support, strategic introductions, Investor Pitch Day, and SAFE-based investment.
- **Community Feedback Survey**: [https://redcap.link/msfah7gg](https://redcap.link/msfah7gg)
